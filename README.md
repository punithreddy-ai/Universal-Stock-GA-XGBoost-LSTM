# Universal Stock Direction Prediction Using GA-XGBoost and LSTM

A deep-learning mini-project for **next-day UP/DOWN classification of Indian NSE stocks** using technical indicators, Genetic Algorithm (GA) feature selection, XGBoost, and a universal LSTM model.

> **Important:** This project is an educational research implementation. It is a methodological adaptation of GA-XGBoost to NSE data, not a reproduction of the reference paper's KOSPI experiment. Model results should not be treated as financial advice or as a trading guarantee.

## Project Overview

The notebook builds a universal stock-direction prediction pipeline:

1. Downloads the NSE stock dataset through KaggleHub.
2. Cleans stock data per `Symbol` and `Date`.
3. Generates a broad set of technical indicators independently for each stock.
4. Performs chronological 70/15/15 train-validation-test splitting per stock.
5. Builds multiple experiments:
   - OHLCV XGBoost baseline
   - Expanded-feature XGBoost
   - Genetic Algorithm feature selection + XGBoost
   - Universal LSTM
   - Majority-class baseline
6. Selects the XGBoost decision threshold using validation data.
7. Evaluates on untouched test data.
8. Performs a leakage audit.
9. Saves model artifacts and tables for future inference/Streamlit deployment.

## Main Models

### GA-XGBoost
Genetic Algorithm feature selection is applied to the technical-indicator feature set. The selected features are then used with XGBoost for next-day direction classification.

### Universal LSTM
A universal LSTM is trained using 60-day sequences without mixing cross-stock sequences.

### Target

The target is:

```text
UP = 1 if Close[t+1] / Close[t] - 1 > 0
DOWN = 0 otherwise
```

## Local Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Universal-Stock-GA-XGBoost-LSTM.git
cd Universal-Stock-GA-XGBoost-LSTM
```

### 2. Create a virtual environment

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Register the Jupyter kernel

```bash
python -m ipykernel install --user --name universal-stock --display-name "Universal Stock (Python 3.10)"
```

### 5. Configure Kaggle

The notebook uses KaggleHub to download the dataset. Configure your Kaggle API credentials according to Kaggle's current authentication instructions.

Never commit:

```text
.kaggle/
kaggle.json
.env
```

### 6. Start Jupyter

```bash
jupyter notebook
```

Open:

```text
Universal_Stock_GA_XGBoost_LSTM_FINAL.ipynb
```

Select the `Universal Stock (Python 3.10)` kernel.

## First Run

For a quick smoke test, set:

```python
TARGET_STOCK = "TCS"
QUICK_MODE = True
```

Then run all cells.

After confirming that the complete pipeline works, use:

```python
QUICK_MODE = False
```

for the larger experiment.

The notebook also supports changing the target stock, for example:

```python
TARGET_STOCK = "RELIANCE"
TARGET_STOCK = "INFY"
TARGET_STOCK = "HDFCBANK"
TARGET_STOCK = "ICICIBANK"
TARGET_STOCK = "SBIN"
```

## Important Configuration

The main configuration cell contains:

```python
TARGET_STOCK = "TCS"
QUICK_MODE = False
SEED = 42
USE_ADJ_CLOSE = False
```

## Leakage and Research Integrity

The notebook explicitly tracks data usage and performs a leakage audit.

The project does **not** hard-code an accuracy target.

An unusually high next-day directional accuracy should be treated as a potential leakage warning and investigated rather than presented as an automatic success.

## Research Comparison

This project is inspired by the methodology of:

**Prediction of stock price direction using a hybrid GA-XGBoost algorithm**

However, this implementation differs from the reference experiment in market, dataset, stock universe, feature implementation, split protocol, target definition, GA settings, and inclusion of a universal LSTM.

Therefore, the reference paper's reported accuracy should not be presented as the result of this project.
